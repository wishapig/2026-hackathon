## 单一职责

将 TaskProgram 中的顺序内存语义转换为 SymbolicGraph。输入是任务域、访问关系、原程序顺序和经声明的假设；输出是去重依赖、源任务域、总数、双向关系程序及能力诊断。接口为 compile_dependences(program, options) → SymbolicGraph。

## 正确性构造

对不同任务 u、v 且 u 在原程序中先于 v，构造以下区域交集非空的冲突：W(u) 与 R(v) 为 RAW，R(u) 与 W(v) 为 WAR，W(u) 与 W(v) 为 WAW。多个区域或多种冲突连接同一任务对时，先求并集形成一条逻辑边。

正确性基线保留全部前向冲突。性能关系允许减少边，但必须维持所有原冲突的可达性。对精确、完整覆盖的同一逻辑位置，可构造连续写版本链，将读者连接到之前的写者，并连接到之后覆盖它的写者；还要保留连续写之间的顺序。一个写之前的多个读者都可能形成 WAR，不能只追踪“最后读者”。跨区域、部分覆盖或不确定别名需要区域细分与证明，否则回到完整冲突关系。

验证依据是原顺序与冲突覆盖，而非某个算法的已知 DAG。通用字典序最值与整数关系操作可降低为计数和枚举程序；无法高效降低的关系明确标为枚举基线或拒绝性能模式。

## 关系表示与降低

逻辑层采用参数化整数域、仿射映射、分段谓词及已支持的常数除数整除/取模。参数步长先在可证明条件下归一化。任意符号乘法和参数除数不能笼统交给传统仿射求解器；q = n / b 的合法性由绑定前置条件保障，其他无法归一化情况诊断处理。

降低目标为有限循环、边界表达式、谓词和 emit 的关系程序。重叠片段优先在编译时拆成互斥片段。前驱计数、后继枚举、源域和任务总数必须从同一个去重关系与域生成；源域是任务域减去所有边的目标投影，不是手写入口任务。

若基数不能闭式计算，可生成带成本说明的枚举计数；若源域不能高效枚举，要暴露其扫描成本。编译复杂度随源码和关系结构增长，不通过枚举评测输入任务来替代符号推导。

优先将循环域降低为高效前驱计数、去重后继、IndexProgram（rank/unrank）及 OrderProgram（完整原顺序游标）。每种能力标明支持条件、游标空间和求值复杂度；无法高效连续索引不等于源码不正确，应拒绝相应快速模式或保留通用路径。原顺序游标必须覆盖全部语义任务，包括初始化与标量操作，作为低成本串行执行依据。

依赖边约简优先于复杂状态压缩，减少实际通知 E，但必须保留全部原始冲突可达性。循环结构还可导出独立范围、亲和和路径提示；运行时批量领取已就绪节点不需要合并 DAG。若进一步合并任务或压缩链，须证明分组覆盖、内部合法顺序、跨组依赖及商图无环；A1→B→A2 不能把 A1/A2 无条件合为整体节点。链进度还需证明门槛、唤醒和寿命，不能用 O(q²) 状态作为所有三层循环的保证。

## 图质量与评分联系

图质量通过运行性能和 Metadata 字节影响评分，没有独立图分项。对同一任务集合，保留参考冲突可达性只证明不漏依赖；全串行链也可能满足这一条件。声称不损失并行度的约简还需保持变换前后可达性相等，额外保守约束显式记录，不作为“必要边”掩盖。去冗余边减少通知但不缩短同权理想关键路径；精确化区域/别名才能消除虚假顺序。

demo 实际调用只使用 cholesky/trsm/madd，包含原地别名和对角 madd 的同输入别名。按真实读写区域和源码顺序推导，不将某层循环的遍历顺序扩展成全阶段屏障；一个 madd 不必等待无关 trsm，下一轮 cholesky 不必等待无关尾块更新。A→L 复制和结束清零不能丢失，可作为显式前后阶段或等价任务，成本计入。

对候选报告原调用数、调度单位数、去重边数、关系片段/表达式大小、计数/枚举复杂度、额外顺序约束与加权路径指标。仅在小图离线计算全闭包；生产路径不为度量图质量额外全图扫描。候选最终以完整计时时间与必要产物字节选择，不以最少节点、最少边或最快离线编译为单独目标。

## 性能与失败边界

主要指标为关系片段数、表达式大小、每个任务计数成本和每条边枚举成本。避免过度分片导致 Metadata 膨胀。简化有编译时间/空间预算，超限时保留正确但较慢的形式并报告，不输出不完整依赖。
