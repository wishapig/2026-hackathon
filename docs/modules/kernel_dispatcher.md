> **实现对照（2026-10-30）**：当前分派在 `src/main.cpp::invoke`，默认 blocked 应用直接调用公开 `cholesky`、`trsm`、`madd`。显式 scalar 应用绑定独立的通用标量表达式解释器；两种符号白名单分开，默认路径不接受标量替代。CMake 默认编译原始 demo 调试内核；设置 `DAG_REQUIRE_OFFICIAL=ON` 和外部库路径后不编译本地内核定义。现有外部链接复验使用 demo archive，最终评测库尚未取得，不能当作官方来源认证。 当前实现见 [实现说明](../implementation.md)。

以下保留模块职责与候选接口；函数名不等同于当前公共 API，实际接口见 `include/dag/core.hpp`。

## 单一职责

依照已解析 ABI 调用 TaskInvocation 指定的算子，并报告同步调用结果。接口为 invoke(invocation, bindings) → InvocationResult。它不计算依赖、不选择任务、不更新其他任务状态。

## 调用路径

GraphEvaluator 生成有类型的参数值，RuntimeBinder 解析调用目标，分派器通过稠密 OperatorId 选择预编译的薄包装函数。ABI 表不包含算法实例、依赖公式或运行顺序。

包装器保持指针、整数宽度、矩阵布局与官方签名一致，避免每任务字符串查找或通用反射开销。不在包装器中复制矩阵、替换算法或合并多次内核调用。参数容量和可证明的地址范围尽可能提前验证，任务相关界限由参数求值器检查。

当前调用表绑定 demo 提供的 cholesky、trsm、madd 三个公开 C 符号，签名见 [算子目录](operator_catalog.md)。推荐调用的 lda=n，块地址由受检参数求值给出，不能把块指针视为连续 b×b 缓冲。三者为 void 返回，失败路径按实际异常/进程行为处理，不读取不存在的返回码。

本地调试可编译 demo 的 kernels_public.cpp 与 kernels_impl.cpp；正式提交只引用公开符号，由评测链接官方库，不定义同名替代实现，不直接调用 __official_*_impl 绕过接口。测试算子注册与正式适配明确分开，扩展算子不改变依赖调度代码。输入复制和全局上三角清零是独立语义阶段，不能偷偷塞进每次算子包装或从执行中省略。

官方库静态链接，禁用 LTO；保留链接映射和库身份。库调用返回才代表同步完成。若实际库异步，必须引入能观察真实完成的适配契约，现有同步实现不能直接宣告完成。

## 并发与失败语义

依赖保护缓冲区访问顺序，算子自身仍需具备声明的重入性。内部线程数由官方契约确定，线程池据此配置；不擅自修改官方内部实现。若某算子要求串行化，调用约束必须显式反映在设计和性能报告中。

对于将来声明有状态返回的扩展算子，非零失败码可转换为 InvocationFailure；当前三个 void 接口只处理已声明可捕获的异常。demo 的 cholesky 在非正 pivot 时可抛异常，trsm 的私有 scratch 分配也可能失败；不能把函数正常返回等同于独立数值校验通过。普通用户态 runtime 无法保证从进程崩溃或无限不返回的内核安全恢复，这不属于可承诺的失败路径。内核失败时不发布正常完成事件，驱动停止新任务并等待其他在途调用退出。
