# SourceFrontend：源码结构化提取

> **非规范文档**：项目唯一需求与验收依据见 [REQUIREMENTS.md](../../REQUIREMENTS.md)。本页仅说明实现、使用方式、设计候选或历史验证；其中的约束性表述不能新增、覆盖或缩小规范要求。

> **实现对照（2026-10-30）**：当前实现位于 `compiler/compile.py`，使用 Python 标准库严格解析结构化 C++ 子集，完整覆盖提供的 demo；没有使用 Clang/LLVM。参数化循环、条件、调用、复制和清零进入程序树，访问表达式由外部 catalog 展开；普通矩阵元素标量赋值和算术被降低为编译器定义的 scalar_expression 调用，实际读写元素随源码推导。支持与拒绝边界以 [编译器说明](../../compiler/README.md) 为准。下文 Clang、坐标域及共享 IR 是原设计候选，不是当前功能。 当前实现见 [实现说明](../implementation.md)。

以下保留模块职责与候选接口；函数名不等同于当前公共 API，实际接口见 `include/dag/core.hpp`。

## 单一职责

将支持范围内的 C/C++ 程序转换为保留顺序语义的 TaskProgram。不生成最终依赖边，不选择线程数或调度策略。输入为源码、编译选项、入口和 OperatorCatalog；输出为参数模式、任务族、域、访问区域、调用参数、程序顺序及诊断。

## 方法与接口

设计接口为 extract_program(source, compile_options, contracts) → TaskProgram。优先使用 Clang AST 保留循环、类型、数组和调用结构；仅在需要验证类型、别名或语义时辅以 IR。前端独立于 runtime 的构建，不把 LLVM 作为运行时依赖。

结构化循环转换为坐标域；嵌套循环和语句位置组成字典序程序顺序。若循环以 b 为步长，只有证明起止、整除与下标对应后，才转换到块坐标 q。源码中的其他标量赋值、初始化和循环携带状态不能被忽略：归入具有明确语义的任务，或诊断该结构尚不支持。

在 TaskProgram 中保留 LoopStructure：循环嵌套、上下界、步长、语句顺序和坐标变换。它支持后续生成连续索引、原顺序游标、增量地址与范围描述，但前端不因存在多层循环就宣称迭代独立，也不把输出块直接认作一条可压缩链。

函数调用以契约描述访问；明确的基本标量算术可形成任务表达式，保持原语句与浮点求值顺序，不启用 reassociation 或 fast-math。demo 已确认计算调用为 cholesky/trsm/madd，另外存在输入复制和结果清零；测试用标量执行器不能替代这三个官方算子。

支持有限结构化整数循环、可降低的参数条件、显式数组访问和已声明调用。运行时浮点控制流、未知副作用或不能证明的指针别名触发带概念位置的诊断，不能静默删除操作或生成无依赖任务。

## 当前输入源码的覆盖要求

首个主输入为 demo 的 `src/baseline/block_cholesky.cpp`，不是人工抄写的固定 DAG。前端需要处理 C++ namespace、参数检查、std::copy、以 b 为步长的三层结构化循环、`&L[row*n+col]` 指针实参、全局上三角赋零及返回。可将经契约确认的 std::copy 和零填充降低为显式缓冲操作/阶段，但必须保留顺序与访问范围；现有严格子集前端已覆盖该 demo；其他 C++ 结构是否支持须查编译器说明。

b>0、n%b==0 与有效尺寸成立后可以证明块坐标变换，所有地址和 ABI 整数转换受检。算子名字仅用于查目录，不用于生成固定后继；madd 对角场景 A/B 相同必须由地址表达式识别。复制先于依赖其内容的调用，结果清零不能被当作无关 I/O 移出图语义或计时。

不要求第一版支持任意 C++。对异常控制、模板展开、别名或循环结构必须给出支持边界；无法保真转换则明确拒绝，不静默删语句。其他算法通过同一提取和依赖流程验证可延拓性，主优化工作集中在正式分块输入。

## 数据与性能边界

IR 不枚举实际 n/b 下的任务。共享重复表达式、保留逻辑区域与地址表达式的区别，并为依赖编译器提供精确的类型、参数界和假设。前端的离线耗时可增加以降低关系复杂度，但不能为某个评测 n/b 单独产出固定图。

前端持有 AST；输出 IR 使用独立存储，离开前端后无需保留 AST。源码调试定位与运行必要数据分开，必要表达式不能放入未计费的调试产物。
