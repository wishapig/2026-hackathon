# RuntimeBinder：参数与资源绑定

> **非规范文档**：项目唯一需求与验收依据见 [REQUIREMENTS.md](../../REQUIREMENTS.md)。本页仅说明实现、使用方式、设计候选或历史验证；其中的约束性表述不能新增、覆盖或缩小规范要求。

> **实现对照（2026-10-30）**：当前绑定分布在 `src/main.cpp`、`src/metadata.cpp` 和 `src/graph.cpp`。支持受检参数/地址计算与非二次幂 b/q；并行路径实例化任务并构造完整 CSR。`serial` 流式原顺序执行；`auto` 在首次计算前按任务数与 planned_workers 选择小任务串行，否则并行。完整物化或执行器准备资源不足时，在复制及所有数值调用前改选流式路径；没有执行失败后的自动重放。总任务/步数默认无上限，显式用户限制仍生效；资源预算由单节点可用量、进程/cgroup 剩余共同约束。实际 CPU 选择为 affinity 与 sysfs NUMA 节点的首个非空交集；拓扑不可读时退到一个允许 CPU。没有显式 mbind/set_mempolicy。 当前实现见 [实现说明](../implementation.md)。

以下保留模块职责与候选接口；函数名不等同于当前公共 API，实际接口见 `include/dag/core.hpp`。

## 单一职责

将只读 Metadata 与实际参数、缓冲区及允许资源组合为可执行的 BoundExecution。接口为 bind_execution(metadata, parameters, buffers, resource_policy, catalog) → BoundExecution。它选择 ExecutionPlan，可调用求值器构建有预算的只读关系缓存；不维护可变计数，不启动任务。

## 绑定内容

验证参数类型、范围和所有前置条件；本题检查 n > 0 及约定范围、b > 0、b <= n、n % b == 0，再派生 q。所有尺寸、地址、任务数量与编码 ID 使用经检查的宽中间值计算，禁止截断溢出。

验证缓冲区容量、形状、步长、对齐与必要别名约束，解析算子 ABI。仅对能证明的关系执行参数常量折叠，产出不可变 BoundGraph 与 InvocationBindings；缺失运行必要声明即失败。参数不允许由 runtime 改成更有利的 b。

接受非二次幂 b 和 q，不增加公开协议没有的幂次限制。缓冲区基址对齐不能证明所有行、块起点均满足相同对齐；按实际 strides 和偏移核对算子声明，不擅自填充矩阵或改动 leading dimension。若官方 ABI 的限制与合法公开参数冲突，报告契约冲突并核实资料。

用户给定测试机器为 Kunpeng-920、2 Socket × 64 核、125 GB。资源策略读取实际允许 CPU 集和 NUMA 拓扑，限定到分配的单节点；不把 socket 等同 NUMA 节点，不把 24 核当上限。若允许集跨节点而没有分配标识，按显式配置选择节点；无配置时采用确定性规则选择一个允许节点并记录。物理核、SMT、节点内存和进程限制分别记录，125 GB 不直接转为调度预算。

BoundExecution 持有 Metadata 生命周期引用、参数常量、缓冲区视图、调用表、资源限制和经校验的任务总数。缓冲区所有权仍在调用者，直到 ExecutionDriver 返回完成或安全失败。绑定器生成资源计划，驱动负责应用 affinity、线程池和实际内存放置。

## 成本与缓存

尽量将仅依赖参数的表达式、分段选择和 ABI 查找移出每任务热路径。缓存键覆盖 Metadata 身份、参数、ABI、缓冲区布局及相关别名条件；包含地址的缓存随实际地址绑定。未知复杂度的任务计数显式计入准备时间。

ExecutionPlan 分别选择状态、关系和计数后端。具备高效 rank/unrank 且完整状态预算可容纳时，第一实现选择连续数组＋隐式关系＋直接原子计数；实际连续存储由 DependencyTracker 在驱动准备阶段分配并初始化。记录 V、最大计数界、ID 宽度、待发布记录、队列、游标、线程栈与可选缓存的实际字节，矩阵及工作区另计。未知项不能按零计，不用平均前沿替代保证。

关系枚举成为瓶颈时，可生成部分缓存或完整 CSR；构建前检查容量界，无法预知时执行有预算的构建并在内核运行前干净放弃该候选。缓存只读且与图身份、参数、ABI/访问契约匹配，不保存已完成状态。按准备＋执行总时间选择，不能只因内存足够就预建全图。

显式模式不可行时，未来可评估按需模式（仍有峰值 O(V) 风险，当前未实现）；当前可显式选择原顺序流式串行模式。后者保持全部语义任务顺序但可较慢；不把尚未证明的窗口/链压缩当成已具备的回退能力。执行中仅调整软展开额度、批量和缓存，模式切换需新执行或证明安全边界。详细成本和条件见 [运行时策略](../runtime_strategy.md)。
