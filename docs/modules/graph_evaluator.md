## 单一职责

对 BoundGraph 的任务域、关系和调用表达式求值。不拥有任务状态、不发送事件、不执行内核。输入保持只读，工作线程使用各自的临时空间与游标。

## 接口与可恢复枚举

| 操作 | 结果 | 要求 |
| --- | --- | --- |
| count_tasks(graph) | 有效任务数 | 与任务域一致，允许缓存绑定结果 |
| rank / unrank(graph, key / id) | 任务与连续 ID 转换 | 双射，不默认 ID 是拓扑序，标明复杂度 |
| enumerate_tasks(graph, cursor, budget) | 全部有效任务 | 供计数初始化，不漏不重，无顺序保证 |
| enumerate_original_order(graph, cursor, budget) | 原程序顺序任务 | 需 OrderProgram 能力，有界游标，覆盖全部语义任务 |
| enumerate_sources(graph, cursor, budget) | 候选源任务批次和续传位置 | 零前驱、去重、最终完整 |
| predecessor_count(graph, key) | 不同前驱数量 | 与去重关系一致 |
| enumerate_successors(graph, key, cursor, budget) | 候选后继批次和续传位置 | 不含自环，边集合一致 |
| evaluate_arguments(graph, key, buffers) | TaskInvocation 的参数值 | 类型、边界、地址溢出经过验证 |

枚举器返回候选批次及其位置，驱动保存未被消费的批次和偏移。求值器的扫描游标可以前进到批次末端，但交接进度只在对应事件被接受后推进；重试先处理剩余候选，不能重新递交已接受事件。调用方不持久保存候选时，必须保留可重建同一批次的旧游标。

预算分别限制输出条数与解释工作量。只限制输出数会使稀疏谓词长时间扫描且不交还控制。无结果但未完成的批次是合法返回，必须携带进度位置；明确区分 yielded 与 exhausted。

## 执行方式与性能

使用通用、类型化的低开销解释器；参数常量已由绑定器折叠，坐标表达式在任务级计算。关系片段优先在编译时互斥化；残余去重必须由关系程序明确实现并计量，不隐含无限增长集合。

计数形式分为常数/闭式、分段闭式和枚举计数，能力报告标注复杂度。后继枚举目标是与实际输出规模接近的工作量，不能暗中扫描所有任务。参数地址乘积可以求值，但不会因此获得非线性依赖证明能力。

坐标展开、任务 ID 编解码、除法与取模必须支持一般正整数 b、q。行主序块 (i,j) 的起点偏移为 i*b*stride_row + j*b*stride_col（步长单位由描述符明确），块内相邻行仍使用矩阵行步长；不能默认块内行步长为 b。位运算快速路径仅在已证明的幂次条件下使用。

禁止每条边进行通用堆分配；临时缓冲区按线程复用，容量受预算约束。若后续引入专门化，必须从同一关系程序自动生成，与解释器差分验证，准备时间和必要产物计费。

连续状态通过 IndexProgram 做直接索引：规则矩形/三角域可使用前缀量及受检整数运算；逆映射复杂度明确，不用未经校正的浮点开根号还原整数边界。无法高效映射的域不能伪装成 O(1)，可拒绝该模式或使用有预算的索引表。

允许绑定器按计划构建只读 CSR 或局部关系缓存，接口仍返回同一去重关系；缓存与解释路径差分验证，构建、解码和触页计入总时间。运行时求值已分析的关系，不重新逐地址做全图冲突分析。

LoopStructure 支持增量地址计算、范围枚举及后续专门化，不是可变就绪状态。未来链模式由求值器返回所需进度门槛，DependencyTracker 判断是否满足，不将计数或进度写入 BoundGraph。
